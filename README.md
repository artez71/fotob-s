# fotob-s

Foto Bus — animasyonlu fotoğraf karavanı showroom sitesi.

Paket HTML, CSS, JavaScript ve kullanılan görselleri içerir.

## Çalıştırma
Bu klasörde terminal açıp çalıştırın:

    python3 -m http.server 8000 --directory dist

Tarayıcı adresi: http://localhost:8000

## Dosyalar
- dist/index.html: içerik, bağlantılar ve iletişim bilgileri
- dist/style.css: ana tasarım ve mobil yerleşimler
- dist/motion.css: animasyonlar ve sinematik sahne
- dist/app.js: etkileşimler, galeri ve animasyon kontrolleri
- dist/assets/: tüm yerel görseller

Telefon ve adres demo bilgileridir. Gerçek kullanımdan önce index.html içindeki telefon, WhatsApp ve adres alanlarını güncelleyin. Harita bağlantısı Pendik Sahil bölgesini gösterir.

Gece etkinliği görseli yapay zekâyla oluşturulmuş konsepttir. Ana karavan görseli sağlanan araç fotoğrafından hazırlanmıştır. Sayfa Google Fonts kullanır; internet yokken sistem yazı tipi devreye girer.
